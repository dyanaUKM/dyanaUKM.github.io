Course Scenario Overview: TTTN3133 Secure Programming equips students with essential skills to detect, exploit, and remediate software security vulnerabilities like SQL injection and broken authentication in real-world applications. Through hands-on lab cases and project implementations, students apply secure coding practices, patch critical security flaws, and document their vulnerability fixes through live tests and video demonstrations.

Labs & Hands-on Exercises

LAB EXERCISE 01

Input Validation

Hands-on exercise focusing on sanitizing user input to prevent injection flaws.

Key Takeaway: Implementing strict input validation highlighted the importance of defense-in-depth at the application boundary. We learned how proper regex matching prevents malicious payload execution.
LAB EXERCISE 02

Authentication Security

Remediating insecure password storage and session handling mechanisms.

Key Takeaway: This lab demonstrated why storing plaintext passwords or using weak hashing is hazardous. Replacing legacy routines with salted bcrypt hashing reinforced secure authentication practices.
